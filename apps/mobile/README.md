# AI Shopping Assistant - Mobile Application

This directory is designated for the React Native / Expo cross-platform mobile client of the SmartShop AI platform.

## Architecture

- **Framework**: React Native with Expo SDK
- **Styling**: NativeWind (Tailwind CSS for React Native)
- **State Management**: Zustand / Shared hooks
- **Voice & AI**: Native microphone input streaming to backend AI agents
- **Shared packages**: Consumes `@smartshop/shared-types` and `@smartshop/api-client`

## Setup (Upcoming)

```bash
npx create-expo-app@latest ./ --template blank-typescript
```
